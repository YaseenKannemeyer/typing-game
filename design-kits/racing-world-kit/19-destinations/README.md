# 19-destinations

Browser-global presentation exports on `WorldKit`: `destinations, destinationLayer(id, layer), destinationScene(id), destinationCard()`. Read the adjacent JavaScript for exact option defaults.

Near/far layers are cosmetic and independent of typing mode.

Shared dependencies and stylesheet order are in `../manifest.json`. Review the interactive scene in `../OPEN-ME.html`. Exported SVGs are in assets/ where applicable; race-control boards are HTML/CSS. Follow `../README-FOR-CLAUDE.md` for integration.
